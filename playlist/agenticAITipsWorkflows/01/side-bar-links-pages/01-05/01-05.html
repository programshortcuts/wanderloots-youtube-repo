Ollama by default only runs a 24,000 context legnth, we need to change it to 64,000

To change Context Window Length, we create a Modelfile 

# Create a Modelfile that extends context
cat > ~/.hermes/cache/scratch/Modelfile << 'EOF'
FROM gemma4:31b
PARAMETER num_ctx 64000
EOF

ollama create gemma4-64k -f ~/.hermes/cache/scratch/Modelfile
