This was a pain to set up, These are the commands to get it started after downloading everything

Change to directory, you want ai to have access to

cd ~/tools-ai

download MCP Server, from njblake here https://github.com/njbrake/filesystem-mcp-server

git clone https://github.com/njbrake/filesystem-mcp-server.git

Start trueforge with this command

npx @truefoundry/trueforge@latest

I made alias trueforge = npx ... in my .zshrc

alias trueforge='npx @truefoundry/trueforge@latest'
